# Security Policy

## Supported version

Security fixes are prepared against the latest version on `main`. Older portable builds are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose or overwrite user files. Use the repository's **Security → Report a vulnerability** flow, and include:

- the affected version;
- a minimal reproduction using generated or non-sensitive files;
- the expected and actual file-system behavior;
- whether original photos, destination files or local settings can be affected.

Do not include private photos, credentials or personal paths. The maintainer will confirm receipt, assess impact and coordinate a fix before public disclosure.
